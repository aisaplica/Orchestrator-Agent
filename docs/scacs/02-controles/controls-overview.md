# Controles AIS

## Filosofía
Controles enriquecidos que encapsulan:
- UI,
- binding con `FormData`,
- comportamiento estándar.

## Categorías

### Entrada de datos
- `AISBusinessField`
- `AISCheckBox`
- `AISRadioButton`

### Lista desplegable
- `AISCatalogo`
- `AISCatalogoTabla`

### Visualización
- `AISGridView`
- `AISLabel`
- `AISTreeView`

### Interacción
- `AISButton`
- `AISChipContainer`
- `AISCollapsibleControl`

### Diálogos
- `AISDialog`
- `AISConfirmDialog`
- `AISMessageDialog`

### Layout
- `AISPanel`
- `AISGroupbox`
- `AISTabControl`

## Regla general
Los controles suelen:
- leer y escribir en `FormData`,
- tener los textos descriptivos asignados en base de datos. Ver [[textos]]
